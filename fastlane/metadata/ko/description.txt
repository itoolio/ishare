ishare는 단순함과 효율성을 염두에 두고 설계된 macOS용 최고의 화면 캡처 유틸리티입니다.

무엇이든 캡처
• 정밀한 선택 도구, 좌표와 색상을 표시하는 픽셀 돋보기, 측정 도구로 영역 캡처
• 모든 윈도우를 그림자와 함께 또는 그림자 없이, 혹은 디스플레이 전체를 캡처하고, 단축키 하나로 마지막 영역 다시 캡처
• 스크롤 캡처로 긴 페이지와 문서를 하나의 이미지로 연결
• 윈도우 캡처에 여백, 둥근 모서리, 그림자가 있는 그라디언트 배경 추가
• 개인정보 보호를 위해 선택한 앱을 흐리게 처리하고 메뉴 막대를 자동으로 가리기
• 기기 내 텍스트 인식으로 화면 어디서나 텍스트를 복사하고, QR 코드에서 링크 추출
• 셀프 타이머, 간격 캡처, 앱별 캡처 프로필
• 모든 기능이 ScreenCaptureKit 기반으로 빠르고 안전하게 동작

화면 기록
• 디스플레이, 윈도우 또는 직접 그린 영역 기록
• 기록에 클릭, 키 입력, 웹캠 버블 표시
• 실시간 레벨 미터를 보며 시스템 오디오와 마이크 녹음
• 저장 전에 기록을 다듬고, 챕터 마커를 추가하고, MP4, MOV, GIF 또는 오디오로 내보내기
• 기기에서 자막을 생성하여 .srt 파일로 저장하거나 비디오에 삽입
• 업로드 전에 해상도, 프레임률, HEVC, HDR, 자동 압축 선택

주석
• 다양한 스타일의 화살표, 선, 도형, 하이라이트, 펜, 마커, 텍스트
• 번호 단계, 이모지 및 기호 스탬프, 스포트라이트, 흐림 효과, 픽셀화
• 핸들과 비율 프리셋으로 자르기, 확대 및 이동, 레이어 사이드바, 재사용 가능한 템플릿
• 완료를 누르면 캡처 후 동작 실행: 복사, 저장, 공유, 업로드

어디로든 업로드
• 별도 설정 없이 Imgur 지원
• chibisafe, Zipline, copyparty, Discord 웹훅, 자체 서버용 사용자 설정 업로더와 ShareX .sxcu 가져오기
• 모든 S3 호환 스토리지 지원, 만료 링크 옵션 제공, 비밀 정보는 키체인에 보관
• 여러 대상에 동시에 업로드하거나 캡처마다 하나를 선택
• 텍스트 조각 업로드, 폴더를 감시해 새 파일 업로드, 실패한 업로드 자동 재시도
• 전용 단축키가 있는 업로드 프리셋, URL 단축기, 민감한 텍스트 자동 가리기
• Apple Intelligence를 지원하는 Mac에서는 어시스턴트가 대화를 통해 업로더 생성

깔끔한 정리
• 명령 팔레트, 최근 업로드, 미리보기를 갖춘 간결하고 사용자화 가능한 메뉴
• 최근 업로드 위젯과 제어 센터의 캡처 제어
• 메뉴 막대 아이콘에 파일을 놓거나 Finder에서 ‘ishare로 업로드’ 사용
• 필터와 서버 측 삭제를 지원하는 검색 가능한 업로드 기록
• 전역 키보드 단축키, 단축어 동작, 공유 확장 프로그램
• 모든 설정과 업로더를 하나의 파일로 백업 및 복원

macOS 26의 Liquid Glass 디자인, 사운드 옵션, 시작 가이드, 11개 언어 번역까지 모두 갖추었습니다.
