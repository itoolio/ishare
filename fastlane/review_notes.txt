ishare is a menu bar app. Click the ishare icon in the menu bar to open the capture menu. Uploading requires a custom uploader, which can be added in Settings > Uploaders, or the built-in Imgur option. Camera (com.apple.security.device.camera): used only for the optional webcam bubble that is overlaid on screen recordings. To try it, open Settings > Recordings, turn on Webcam > Show webcam, then choose Record > Screen or Region in the menu; a round camera preview appears over the recording. Microphone (com.apple.security.device.audio-input): records your voice into screen recordings when Settings > Recordings > Record microphone is on, and powers the input level meter there. Input Monitoring is requested only when Settings > Recordings > Show keystrokes is turned on, to display pressed keyboard shortcuts in recordings. Accessibility (event posting) is used only for the optional automatic scrolling in scrolling capture, which is off by default: when the user turns on Settings > Screenshots > Scrolling Capture > Scroll automatically, ishare asks for the permission with an explanation and then scrolls the area the user selected so a long page can be stitched into one image. It is never requested otherwise; without it the user scrolls manually. App group (com.apple.security.application-groups): the app writes a small list of the most recent uploads with thumbnails to the shared container so the Recent Uploads widget can show them, and the Share menu extension hands shared files to the app through it. The widget extension only has the sandbox and app group entitlements. The Capture Region control in Control Center and the widget button open ishare to start a region capture. Diagnostics: crash and hang reports from MetricKit are stored only on the Mac and are never uploaded; Settings > Advanced > Diagnostics lists them and can open a prefilled GitHub issue that the user reviews and submits themselves. Cleanup of old local captures in Settings > Advanced is off by default and only moves ishare's own captures in the save folders to the Trash. The Movies folder entitlement was removed because it was not needed. Keychain group (keychain-access-groups): S3-compatible uploaders need a secret access key; the app stores only these user-entered keys as synchronizable iCloud Keychain items in its own keychain group so they are available on the user's other Macs. Nothing else is stored there.
