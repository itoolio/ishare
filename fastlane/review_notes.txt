ishare is a menu bar app: click its menu bar icon to open the capture menu. Uploads use the built-in Imgur option or a custom uploader added in Settings > Uploaders.

Camera (com.apple.security.device.camera): for the optional webcam bubble over screen recordings and for recording or capturing the screen of an iPhone or iPad connected over USB, like QuickTime Player. To try the bubble, turn on Settings > Recordings > Webcam > Show webcam, then choose Record > Screen or Region. To try a device, connect an unlocked iPhone over USB and choose Record iPhone or Capture iPhone Screenshot in the menu.

Microphone (com.apple.security.device.audio-input): records your voice into screen recordings when Settings > Recordings > Record microphone is on, and drives the level meter there.

Input Monitoring is requested only when Settings > Recordings > Show keystrokes is turned on, to show pressed shortcuts in recordings.

Accessibility (event posting) is only for optional automatic scrolling in scrolling capture, off by default. When the user turns on Settings > Screenshots > Scrolling Capture > Scroll automatically, ishare explains and asks for it, then scrolls the selected area so a long page is stitched into one image. Without it the user scrolls by hand.

App group (com.apple.security.application-groups): the app writes its latest uploads with thumbnails to the shared container for the Recent Uploads widget, the Share extension hands files to the app through it, and the bundled command-line tool and ishare:// URL actions exchange small request and response files with the app there. The widget and the command-line tool only have the sandbox and app group entitlements.

Keychain group (keychain-access-groups): stores only secrets the user types in, such as S3 secret keys, WebDAV and SFTP passwords or keys, cloud sign-in tokens and webhook secrets, as iCloud Keychain items in the app's own group so they reach the user's other Macs.

Photos (com.apple.security.personal-information.photos-library): only for the optional Photos uploader. Create it in Settings > Uploaders > Create > Photos; ishare asks for access then and adds uploaded captures to the chosen album ("ishare" by default). Deleting such an upload from history removes the photo after the system confirmation.

Local network sharing (com.apple.security.network.server): only when the user picks Share on Local Network for a capture or history item, ishare starts a small HTTP server on a random port that serves that one file at a random, unguessable link, so it can be opened on a phone on the same network. The link expires after the time or number of downloads the user chose in Settings > Advanced > Sharing, and the server stops when nothing is shared or ishare quits. To try it, take a capture, right-click Copy in the result toast and choose Share on Local Network; a QR code appears.

Other features need no further entitlements: folder and iCloud Drive uploaders write to a folder picked in the open panel; WebDAV, SFTP, Dropbox, Google Drive, OneDrive, GitHub uploads and webhooks use the network client entitlement; app audio selection, instant replay (off by default, keeps only the last seconds in temporary files, saves only when asked) and the recording notes panel (visible only to the user, excluded from recordings) use the Screen Recording permission. MetricKit crash reports stay on the Mac; Settings > Advanced > Diagnostics can open a prefilled GitHub issue the user submits themselves. Cleanup of old local captures is off by default and only moves ishare's own captures to the Trash.
