ishare is a menu bar app. Click the ishare icon in the menu bar to open the capture menu. Uploading requires a custom uploader, which can be added in Settings > Uploaders, or the built-in Imgur option. Camera (com.apple.security.device.camera): used only for the optional webcam bubble that is overlaid on screen recordings. To try it, open Settings > Recordings, turn on Webcam > Show webcam, then choose Record > Screen or Region in the menu; a round camera preview appears over the recording. Microphone (com.apple.security.device.audio-input): records your voice into screen recordings when Settings > Recordings > Record microphone is on, and powers the input level meter there. Input Monitoring is requested only when Settings > Recordings > Show keystrokes is turned on, to display pressed keyboard shortcuts in recordings. Accessibility (event posting) is used only for the optional automatic scrolling in scrolling capture, which is off by default: when the user turns on Settings > Screenshots > Scrolling Capture > Scroll automatically, ishare asks for the permission with an explanation and then scrolls the area the user selected so a long page can be stitched into one image. It is never requested otherwise; without it the user scrolls manually. App group (com.apple.security.application-groups): the app writes a small list of the most recent uploads with thumbnails to the shared container so the Recent Uploads widget can show them, and the Share menu extension hands shared files to the app through it. The widget extension only has the sandbox and app group entitlements. The Capture Region control in Control Center and the widget button open ishare to start a region capture. Diagnostics: crash and hang reports from MetricKit are stored only on the Mac and are never uploaded; Settings > Advanced > Diagnostics lists them and can open a prefilled GitHub issue that the user reviews and submits themselves. Cleanup of old local captures in Settings > Advanced is off by default and only moves ishare's own captures in the save folders to the Trash. The Movies folder entitlement was removed because it was not needed. Keychain group (keychain-access-groups): S3-compatible uploaders need a secret access key; the app stores only these user-entered keys, and the optional default password the user sets for password-protected links of a custom uploader, as synchronizable iCloud Keychain items in its own keychain group so they are available on the user's other Macs. Nothing else is stored there. Photos (com.apple.security.personal-information.photos-library): used only by the optional Photos uploader. To try it, open Settings > Uploaders, click Create > Photos and save; ishare asks for Photos access only at that point, then adds each capture uploaded to that uploader to the chosen album (an "ishare" album by default, created if missing). Photos uploads produce no link. Deleting such an upload from the history removes the photo after the system confirmation. Folder and iCloud Drive uploaders copy captures into a folder the user picks in the open panel and need no extra entitlement. Keychain group (keychain-access-groups): S3-compatible uploaders need a secret access key; the app stores only these user-entered keys as synchronizable iCloud Keychain items in its own keychain group so they are available on the user's other Macs. Screen recording extras use only the existing Screen Recording permission and add no entitlements: Settings > Recordings > Audio source can limit recorded sound to apps the user picks, read from the list of running apps on this Mac. Instant replay in Settings > Recordings is off by default; when the user turns it on, ishare keeps recording the main display into a few temporary files on the Mac holding only the last 30 seconds to 2 minutes, deletes older parts continuously, pauses while the screen is locked or the battery is below 20%, and only saves or uploads a clip when the user presses the Save Instant Replay shortcut or menu item. The optional recording notes panel is visible only to the user and is excluded from recordings and screenshots; its text is stored only in the app's preferences on this Mac.
