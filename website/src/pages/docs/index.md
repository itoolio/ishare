# Documentation

- [Custom uploaders](/docs/iscu/) is the quick reference for `.iscu` files: HTTP uploaders, response templates, password-protected and expiring links, S3-compatible storage and local destinations.
- [Developer documentation](/docs/documentation/ishare/) is the full DocC reference generated from the app: every ISCU field with examples, and a guide to writing a new kind of uploader with the `Uploader` protocol.
- [Example uploaders](/uploaders/) are ready-made `.iscu` files for popular services.
